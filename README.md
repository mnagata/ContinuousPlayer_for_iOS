# ContinuousPlayer for iOS

TVアニメのOP/EDを中心に、フォルダー内の動画・音声を連続再生するアプリです。iPhone / iPad、Mac Catalyst、Apple TVに対応し、SwiftUIとAVFoundationで実装しています。

## 主な機能

- 選択したファイルから、同じフォルダー直下のメディアを連続再生
- ファイル名に応じたOP/EDの並べ替え
- 端末・USBストレージのフォルダー登録とアクセス許可の保存（iPhone / iPad / Mac）
- DLNAメディアサーバーのフォルダー閲覧とMP4／M4Vの連続再生
- タッチ・外部キーボード・Siri Remoteによる再生操作
- ファイル情報・映像／音声形式・音声出力情報の表示
- iPhone / iPadの縦画面・横画面に対応

詳細な挙動、制約、プラットフォームごとの差異は [アプリケーション仕様](docs/spec.md) を参照してください。

## 動作環境

| 版 | 対応OS | メディアの取得元 |
|---|---|---|
| iPhone / iPad | iOS / iPadOS 26.0以上 | 端末・USBストレージなどのフォルダー、DLNA |
| Mac Catalyst | macOS 26.0以上 | Mac上のフォルダー・外部ストレージ、DLNA |
| Apple TV | tvOS 26.0以上 | DLNA |

端末・Mac上の対象拡張子は `.mp4` / `.m4v` / `.mp3` / `.flac` / `.m4a` / `.aac` / `.wav` / `.ogg` / `.opus` です。DLNAではMP4／M4Vを対象とします。実際に再生できる形式はOSと端末に依存します。

USB再生には、端末がストレージを認識し、標準のファイル画面から対象フォルダーを選択できる必要があります。DLNA再生には、NASなどのメディアサーバーと同じLANへの接続、ローカルネットワークへのアクセス許可が必要です。

## 使い方

### 端末・USB・Macのファイルを再生する

1. ホームの「OP / EDを選ぶ」→「フォルダーを追加」→「端末のフォルダー」を選びます。
2. 標準のファイル画面で対象フォルダーを選択し、アクセスを許可します。登録だけでは再生は始まりません。
3. 保存済み一覧で登録したフォルダーを開き、再生を開始する動画・音声ファイルを選びます。

選択したファイルから、同じフォルダー直下のメディアをOP／ED順に連続再生します。サブフォルダーは一覧から開けます。フォルダーの登録は次回起動後も保持され、長押し・右クリック、またはiPhone / iPad / Macの左スワイプから確認して解除できます。実ファイルは削除しません。

フォルダーの追加には標準のファイル画面を使い、再生するファイルの選択には検索窓のないアプリ内一覧を使います。登録ルートから上へ戻ると保存済み一覧に進みます。再生中の追加・登録解除では元セッションを保ち、一覧全体のキャンセルで元の動画へ戻ります。

### DLNAサーバーから再生する

1. NASのメディアサーバーを起動し、対象フォルダーをメディアインデックスに登録します。
2. 「OP / EDを選ぶ」→「フォルダーを追加」→「DLNAサーバー」を選びます。Apple TVも同じ流れでDLNAを選びます。
3. NASのIPアドレスまたはホスト名を入力し、「接続」を選びます。初回のローカルネットワークアクセスを許可してください。
4. 対象フォルダーを開き、「このフォルダーを登録」を選びます。保存済み一覧に戻り、登録したフォルダーから動画を選びます。

Synologyでは通常、一覧取得にポート50001を使います。DSM管理画面のURLや共有フォルダーのパスでは接続できません。通常のiPhone / iPad実機ビルドとApple TVではアドレスを指定して接続します。接続設定やエラーの詳細は [DLNA仕様](docs/spec.md#dlna再生synologyメディアサーバー) を参照してください。

### 再生を操作する

| 環境 | 再生／一時停止 | 前／次のファイル | 10秒巻き戻し／早送り |
|---|---|---|---|
| iPhone / iPad | 映像中央をタップ | 右／左スワイプ | 映像の左／右をタップ |
| Mac | 映像背景の任意の位置をクリック、Space／Enter | ←／→ | ↑／↓、またはShift＋←／→ |
| Apple TV | 決定、再生／停止ボタン | 映像フォーカス中の左／右方向・同方向スワイプ | 上／下方向・同方向スワイプ |

iPhone / iPadでは、一時停止すると「ホームに戻る」「ファイル一覧」「メディア情報」などの操作ボタンが表示されます。Macの通常ウィンドウでは上部操作に標準タイトルバーを使用します。「ファイル一覧」で一覧を開き、「キャンセル」で元の位置・再生意図へ戻れます。表示中に割り込みがあれば停止を維持します。選択確定は同じファイルでも0秒から再生します。Apple TVも戻る1回で現在のDLNA一覧を重ね、キャンセルで同じ復元規則を使います。

再生失敗では自動で次へ進まず、現在の項目で停止します。「再試行」は最後に確認できた位置から、「次のファイル」は0秒から明示的に再生します。「閉じる」はエラー表示だけを閉じます。接続・アクセス許可が復旧しても、再試行するまで再開しません。メディア情報はApple TVも含め、ファイル、映像・音声形式、音声出力の順に表示します。

映像にフォーカスがあるとき、Space／Enterで再生切替、Esc／Oでファイル一覧、Iで情報、Hでホームへ戻ります。長押しは1押下1操作です。Tab／Shift＋Tabで部品間を移動し、ボタン上の矢印はUI移動に使います。一覧は上下で選択、左右・Page Up／Downで表示件数分のページ移動、Backspaceで親へ、Escで選択全体をキャンセルします。文字入力・IMEと最前面の画面を優先し、音量はOS・機器の操作を使います。

直接タッチのダブルタップは1回分です。マウス／トラックパッドの背景ダブルクリックも切替1回で、ドラッグやスクロールでは再生位置を変えません。非アクティブなMacの最初のクリックはフォーカス取得だけに使います。

Macでは再生中にEscを押すと一時停止し、再生中のファイルがあるフォルダーの一覧を開きます。再生中だったファイルが強調表示され、その位置までスクロールします。

Macのタイトルバーには再生中のファイル名（DLNAではサーバーが公開するタイトル）を、メディアの拡張子を除いて表示します。次のファイルに進むと更新され、ホームに戻るとアプリ名に戻ります。

各版とも上端左にタイトル、右に「ホームに戻る」「ファイル一覧」「メディア情報」、下端中央に前・10秒戻す・再生／一時停止・10秒進める・次を配置します。iPhone / iPadの縦画面も映像に操作部を重ね、詳細はメディア情報に集約します。既知の末尾拡張子だけをタイトル・一覧で省略し、同名になるファイルには形式バッジを付けます。元名は読み上げ・ツールチップ・メディア情報で確認できます。

Macの通常ウィンドウでは上部に標準タイトルバーを使い、全画面では同じ順の画面内操作へ切り替えます。「全画面にする／全画面を解除」のボタンとMac標準操作を利用でき、再生開始では現在のウィンドウ状態を変えません。ポインター操作時は3秒無操作で操作部・カーソルを隠します。ボタン上・操作部へのフォーカス・ダイアログ・VoiceOver操作中は表示を維持し、音声のみの再生では常時表示します。タッチやTVでは一時停止で操作部を表示し、再開で隠します。バッファリングだけでは表示状態を切り替えません。

Macの起動時ウィンドウは、動画表示領域が16:9になり、タイトルバーを含む全体が表示先ディスプレイの幅・高さの60％以内に収まるサイズで開きます。Retinaの表示倍率を反映した画面サイズを基準に計算し、起動後は自由に拡大・縮小できます。

Macでは「ヘルプ」→「ContinuousPlayerヘルプ」で、日本語の操作ガイドをmacOS標準のヘルプビューアに表示できます。ガイドはアプリに同梱され、ネット接続なしで読めます。

最後のファイルで再生は終了します。リピートや再生位置の永続保存はありません。

## ビルドと検証

macOSと、本プロジェクトのSwift構文・各OSのSDKに対応するXcodeが必要です。一部のテストと合成素材の生成にはPython 3、動画素材の生成にはFFmpegを使用します。

`ContinuousPlayer_for_iOS.xcodeproj` をXcodeで開き、次のスキームと実行先を選んでRunします。実機では開発チーム・署名の設定が必要です。

| 版 | スキーム | 実行先 |
|---|---|---|
| iPhone / iPad | `ContinuousPlayer_for_iOS` | 実機またはiOS Simulator |
| Mac Catalyst | `ContinuousPlayer_for_iOS` | My Mac (Mac Catalyst) |
| Apple TV | `ContinuousPlayer_for_tvOS` | 実機またはtvOS Simulator |

コマンドラインでのiOSシミュレーター向けビルド：

```sh
xcodebuild -project ContinuousPlayer_for_iOS.xcodeproj \
  -scheme ContinuousPlayer_for_iOS \
  -configuration Debug \
  -destination 'generic/platform=iOS Simulator' \
  -derivedDataPath /tmp/ContinuousPlayer-build \
  build CODE_SIGNING_ALLOWED=NO
```

Mac Catalystのローカル開発用ビルドと起動：

```sh
./script/build_and_run.sh
```

macOS上での基本テスト：

```sh
sh scripts/test-enumeration.sh
sh scripts/test-playback.sh
sh scripts/test-playback-input.sh
sh scripts/test-playback-integration.sh
sh scripts/test-dlna.sh
```

UIテスト、合成素材の生成、追加のビルド・署名設定は [アプリケーション仕様](docs/spec.md) を参照してください。ビルドだけでは実機のアプリは更新されません。端末への反映にはXcodeのRun、または別途インストールが必要です。

共通操作の回帰試験と、実機での確認範囲・未確認事項は[仕様書の「回帰試験と実機確認」](docs/spec.md#回帰試験と実機確認)を参照してください。
