# tvOS対応・検証記録

2026-09-23、Xcode 27 SDKで実施。アプリの最小対応バージョンはtvOS 26.0。

## 実装

- `ContinuousPlayer_for_tvOS` ターゲット・共有スキームを追加。iOS版の再生、メタデータ、DLNA、並べ替え処理を共通利用。
- NASアドレス指定、保存した接続先への再接続、フォルダー閲覧、MP4／M4V連続再生。
- テレビ向けホーム・全画面再生・メディア情報、Siri Remoteの方向／選択／再生停止／戻る操作。
- tvOSにも音声セッション、割り込み、出力切断の処理を適用。
- iOS専用のUSBアクセス、ファイル選択、検証画面はtvOSターゲットから除外。
- tvOSではSSDPを無効にし、初期版はアドレス指定接続を使用。
- 既存のブランド図形からtvOS用のレイヤー付きアイコンとトップシェルフ画像を生成。

## IP設定画面の視認性改善

Apple TV実機でIP設定画面が暗く見えにくいとの報告を受け、NASブラウザーを独立したライト表示に変更。
不透明な明るい背景、白いIP入力欄、選択中の青い枠線を使用し、キャンセルとセクション見出しも濃くした。
再生画面は従来の暗い背景を維持する。iOSの配色は変更しない。
シミュレーターのIP設定画面をスクリーンショットで確認し、既存のSiri Remote操作テストとiOSビルドで検証。

## 戻る操作での一覧位置復元

DLNAブラウザー内で親フォルダーごとに最後に開いた項目のObject IDを保持する。
親一覧が再表示されたらその行を中央付近までスクロールし、リモコンのフォーカスを復元する。
一覧を保持できている場合は戻るたびの再取得を避け、明示的な「再読み込み」は引き続きNASから取得する。
再生画面からの復帰では選択したファイル行を復元する。保存範囲はブラウザーの表示セッション内のみ。

35フォルダーの親一覧、25フォルダーの子一覧を返す模擬NASを追加し、Apple TVシミュレーターで次を検証した。

- Folder 25 → Child 20 → ファイル一覧から、Menu（戻る）でChild 20が表示・選択される。
- 直後の下方向操作でChild 21へ移動する。
- さらに戻るとFolder 25が表示・選択される。
- Folder 25を再度開くと最後に開いたChild 20の位置を復元する。

iOS Simulatorビルドと既存DLNA通信・HTTP再生テストも成功。

## 左右タップとスワイプの分離

映像表示中の前後移動は、Siri Remoteの間接タッチを受けるUISwipeGestureRecognizerで判定する。
左右の方向コマンドは無視し、スワイプ認識ではボタン押下を受け付けない。
左スワイプは前の動画、右スワイプは次の動画。中央の選択、再生／停止、戻る操作は維持する。
操作ボタン表示中やフォルダー一覧では、通常どおり方向操作でフォーカスを移動できる。

UIテストには左右ボタンを押しても再生中のファイルが変わらない確認を追加。
XCUIRemoteはボタン押下のみを提供するため、実物のタッチ面でのスワイプ／軽いタップの区別はApple TV実機で確認する。

## DLNAサーバー選択画面の統一

iOS版のセクション構成に合わせ、tvOSのサーバー選択一覧をグループ形式に変更した。
横幅を1320ポイントまでに抑えて中央に配置し、接続設定・サーバー・案内を角丸の項目で区別する。
明るい背景とIP入力欄のフォーカス枠を維持し、説明文とキャンセルの文字色も濃くした。
Apple TVシミュレーターで画面を確認し、既存のNAS接続・連続再生・戻る操作テストを実行した。

## DLNAサーバー選択画面のiOS風デザイン

tvOSのサーバー選択は、幅を抑えたグループ形式の一覧、薄いグレーの背景と白いセクション背景を使用する。
接続設定、サーバー一覧、補足案内を分け、補足説明は小さめの濃いグレーの文字で表示する。
操作のアクセントは青とし、IP入力欄の選択枠とライト表示を維持する。
